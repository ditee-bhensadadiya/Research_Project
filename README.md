This project demonstrates a Reinforcement Learning-based autonomous car using ESP32 and Q-Learning.
The system is first trained in a virtual grid environment built using Python, where the agent learns the optimal path from a start point to a goal while avoiding obstacles.
Once training is complete, the learned path is transmitted wirelessly to the ESP32 microcontroller via Wi-Fi. The car then executes this path in real-world conditions using motor control.

🔹 Key Features:
• Q-Learning based path planning  
• Dynamic grid environment with GUI  
• Wireless communication using ESP32  
• Real-world execution of trained model  

🔹 Technologies Used:
Python, Reinforcement Learning (Q-Learning), ESP32, IoT, DC Motors, TB6612FNG Motor Driver  

🔹 Applications:
Autonomous vehicles, warehouse robotics, delivery systems, and intelligent navigation
